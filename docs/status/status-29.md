## 概要

status-28 の「Phase 2 に入る前に実機データと突き合わせる」は、実機データも想定機も
無いので果たせない。代わりに **Pinto & Tadmor (1970) の解析 RTD** を真値の供給源として
自前で再導出し、ykep の粒子追跡 RTD が浅溝極限 `H/W → 0` でそれに収束することを
ゲート G5 として固定した。公開 Artifact: https://claude.ai/code/artifact/2b9bd8c5-6c35-4f7f-986f-dcf762ea43a9

```
  真値の層     pinto_tadmor.py    ŵ = ξ + 3rξ(1−ξ), û = 3ξ²−2ξ の流線対 g(ξ)=g(ξ_c)
                                  周回平均で積分した F(t/t̄)。t_min/t̄ = 3/4、r に依らない
               ↓ F_PT
  比較の層     compare_rtd()      分位点 p10/p50/p90 の比 − 1、分位関数 t(F) の相対偏差の
                                  F∈[0.05,0.9] 平均（横方向）。rtd.weighted_ecdf を使う
               ↑ t_res, weight
  既存の層     ExtruderFlowProcess → ParticleTrackerProcess → RTDProcess（無変更）
```

## 決まったこと（設計上の論点）

| 論点 | 結論 | メカニズム |
|---|---|---|
| 文献の 3 仮定を ykep 側でどう満たすか | **δ = 0、z = 0.5 m、cfl = 0.1** | 無限幅 → 隙間の速い経路を消す（隙間流量比 ≈ 2tanφ(δ/H)L/W は H/W → 0 で消えない）。周回無限回 → 周回 ≈ 5 回。流線追従 → 時間刻みを小さく |
| 規格化 | **t̄_∞ = t̄_theory·F_d** | 側壁は流量を F_d 倍に減らすが、分位点を担う溝中央の流線は側壁を知らない。極限では F_d → 1 なので主張は変わらない |
| 曲線の距離 | **横方向（分位関数）の L1** | 文献の F は t_min で垂直に立ち上がるので縦の |ΔF| は意味が無い。max は 1 粒子/セルの階段幅に汚染される |
| 背圧の普遍性 | **有限幅でも成立**（r = −0.3 で p50 +0.1%） | 恒等式 3ξ(1−ξ) = ξ − (3ξ²−2ξ)。横断分布は周回平均で消えるので周回平均速度は (1+r) 倍になるだけ。有限幅では r の定義に (F_d + rF_p)/(1+r) を入れる |
| 短時間側は周回数で決まる | **周回 1〜2 回で t_min/t̄ = 2/3、5 回以上で 3/4** | 軸方向速度 3ξ(1−ξ) は ξ = 1/2 で最大。周回する前に抜ける粒子は入った高さで滞留時間が決まる。周回時間 ≈ W/V_x は H に依らない |
| 閉チャネルの平均が「当てにならない」（status-28 §3.1） | **大半は数値効果（流線ドリフト）で、物理ではない** | 既定 cfl = 1.0 は ψ 双一次補間のセル境界を 1 ステップで跨ぎ、RK4 が流線を横切る。周回を重ねると壁際に流れ込み、4.5% の粒子が最大ステップで止まって外挿され ⟨t⟩/理論値 = 3.19。cfl = 0.1 で 0.998。G4b（周回 2 回）では見えないので判定不変。既定値は変えず docstring に記録 |
| 隙間の効き方 | **裾を伸ばす（p90 +7.6%）、短時間側はわずかに速い（p10 −2.3%）** | 隙間を越える材料はバレル直下から出発するので軸方向速度 ≈ 0。隙間にいる間は進まない |
| 実機の計量部 5D（周回 ≈ 2 回） | **短時間側は文献曲線より広い**のがモデルの帰結 | 文献照合は「長い極限で一致する」ことの確認であって、実機の RTD が文献曲線だという意味ではない |
