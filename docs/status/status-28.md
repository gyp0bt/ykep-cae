## 目的

手元の 2D FVM Brinkman 補正 Navier-Stokes ソルバーが「メッシュ細分化・流速増加で
収束エラーで落ちる」現象を、本リポジトリ上で**同じ構成のソルバーを新規実装して再現**し、
失敗機構を切り分ける（学習目的の実験、STA2 防止ルールに従い未収束は未収束と記録）。

## 問題設定（ユーザ指定）

| 項目 | 値 |
|---|---|
| 領域 | 0.7 × 0.4 m、厚さ 1e-3 m |
| 物性 | ρ=1000, μ=1e-3, μ_brinkman=1e-3 |
| Brinkman 項 | −(12 μ_b / h²) u（Hele-Shaw 平行平板の深さ平均抵抗。係数 12 は本実装の仮定） |
| inlet | 左壁、上から 0.05 空けて高さ 0.1（y∈[0.25,0.35]）、速度指定 |
| outlet | 左壁、下から 0.05 空けて高さ 0.1（y∈[0.05,0.15]）、圧力 0 |
| flat モデル | 全域 h=1e-3 |
| uturn モデル | U ターン経路（往路/折返し/復路、幅 0.1）のみ h=1e-3、残り h=1e-5 |
| ベースメッシュ | 72×48、細分化 2×2、4×4 |
| 流速 | 0.1 / 1 / 2 m/s（inlet 高さ基準 Re = 1e4 / 1e5 / 2e5） |

## 実装（`xkep_cae_fluid/brinkman_flow/`）

| 要素 | 実装 |
|---|---|
| 離散化 | 同位置格子 FVM、未知数 [u, v, p]、連続式に Rhie–Chow 面流束（d_f=V/a_P） |
| 対流 | 1 次風上 / 2 次風上 + Venkatakrishnan（K=5、Green–Gauss 勾配）を選択 |
| 残差 / ヤコビアン | 残差は選択スキーム、ヤコビアンは常に 1 次風上（解析的、RC の p 依存を含む。FD 検証済み） |
| 外側 | Newton（ラインサーチ無し、オプションで Armijo） |
| 内側 | GMRES（`jfnk`: 有限差分 J₂v、前処理 LU(J₁)、`scipy.sparse.linalg.splu`）／`defect_correction`: J₁δ=−R₂ を LU 直接 |
| 擬似時間 | 対角に ρV/Δτ、Δτ = CFL·Δx/max(|u|+|v|, 0.1·U_in)、SER で CFL を残差比で増減（cfl_init=5、成長率上限 2） |
| 陰的緩和 | 運動量対角を a_P/α_u（α_u=0.7） |
| 失敗検出 | NaN / 相対残差 > 1e6 で発散 / 反復上限 60 → `converged=False` + `failure_reason` |

## 解釈

1. **定常解は存在する**（少なくとも 72×48・144×96 の全 U）。同じ離散化・同じメッシュで
   設定だけ変えた変種が収束しているので、「落ちる」のは定常解の不在ではなく
   **Newton の大域化（擬似時間制御）の失敗**。
2. **失敗の起点は常に 1 反復目**。静止初期場から cfl_init=5 で踏み出すと、線形化点 u=0 では
   対流ヤコビアンがほぼ零（Stokes–Brinkman 問題）なのに、更新後に評価する残差は
   ρu·∇u を含むため、‖R‖ が 20〜175 倍に跳ね上がる。増幅率は U とメッシュ細分化の両方で
   単調に増える（uturn: 72×48 → 288×192 で U=1: 12.5×→22×→52×、U=2: 31×→75×→175×）。
   これが「流速を上げても、メッシュを細かくしても落ちる」の正体。
3. その後は SER が CFL を 1/10 ずつ下げて回復を図るが、跳ね上がった状態での線形化は
   GMRES が収束しなくなり（40 反復超で未収束が頻発）、更新が信頼できず発散（uturn）か
   長い停滞（flat）に至る。**発散判定に至る前に GMRES 未収束が出るのが前兆**。
4. **効くもの**: 初期 CFL を下げる（B）、静止域の擬似時間速度スケールを U_in にする（G）、
   defect correction（E: J₁ の余分な散逸が実質的なダンピング）。
   **効かないもの**: 1 次風上（D）。リミターや 2 次精度は原因ではない。
   ラインサーチ（C）と継続法（F）はモデル依存で不安定（flat の継続法は U=1 解から出発しても発散）。
5. **flat が uturn より悪い理由**: uturn は Brinkman 貫通項 1.2e8·u が領域の大半で支配的で、
   これがヤコビアンの対角を強く支配する（実質的な減衰項）。flat は貫通項が 1.2e4·u しかなく、
   Re=1e5〜2e5 のジェットが自由領域に噴き出す問題なので、擬似時間以外にダンピング源がない。
6. **未解決**: cfl_init=0.5 でも uturn 144×96 U=2 は 150 反復で 3.1e-5（単調減少だが遅い）、
   288×192 は未試験。「初回増幅」を抑える本質的対策（静止場からの Stokes 初期解、
   CFL の残差増幅に基づく後退＋再試行、U のランプ）が次の課題。

## 速度・圧力分布（cfl_init=0.5 で収束した場）

`experiments/brinkman_uturn/plot_fields.py` で `results_cfl0.5/*_fields.npz` から描画。図は `experiments/brinkman_uturn/output/*.png`。

- **uturn**: 流路内はほぼ一様なプラグ流（Hele-Shaw 的）。U ターン内側コーナーで剥離し、
  U=2 では内側に最大 3.3〜3.6 m/s（U_in の 1.7 倍）のジェットと外側に低速域ができる。
  圧力は往路→復路で線形に降下し、inlet で約 35 kPa（U=0.1 では 1.7 kPa、Hele-Shaw 圧損と整合）。
- **flat**: inlet ジェットは Brinkman 抵抗で約 0.1〜0.15 m で減衰し（減衰長 ρU h²/(12μ_b) ≈ 0.17 m）、
  outlet へ短絡する。右側 0.2 m 以降はほぼ静止。圧力は inlet 近傍の局所的な高圧と outlet の低圧のみで、
  慣性が効くのは左端の狭い領域だけ。
- 144×96 と 72×48 で場の構造は同じ（メッシュ依存性は小さい）。
