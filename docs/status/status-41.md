## 1. 何を求められたか

gyp さん: 「入れ子反復はいいですが、あんまり細かくやるとトータル時間伸びます。**目安どの程度が最適か肌感を得たい**。
**SER の制御も良いところを調査**ください」。

答えを先に書く。

- **入れ子は最粗格子（72×48）から 2 倍ずつ全段カスケード、各段は tol 1e-4 まで。** 粗格子側の合計は
  細格子 1 本の 7〜10% で、段を増やしても増えない（各段のコストが 1/4 ずつ落ちる等比級数）。
  「細かくすると伸びる」のは段数ではなく**粗格子の解き込み**で、1e-6 まで解くと 288×192 の段だけで
  41 s かかる（1e-4 なら 12 s、細格子側の反復は同じ）。細格子側の Newton 反復は初期場の質で決まる
  下限（288×192 で 13、576×384 で 20〜30）があり、これは段数では減らない。
- **SER は乗法形（成長 2 倍 / 減少 0.1 倍）のままで、`cfl_init` を 0.5 → 0.25 に下げ、線形解が実質失敗した
  ステップを棄却する安全規則を足す**のが良いところ。成長率・減少率・上限・前処理更新則・古典形目標則・
  GMRES 余力則はいずれも掃引で劣った。発散していた uturn 144×96 U=1 / U=2 が収束するようになった。

## 2. 全体像: 何が時間を決めているか

```
  総時間 = Σ_段 [ N_Newton(段) × (組立 + n_GMRES × 前処理適用) ]

  粗格子 (1/4 のセル)            細格子
  ┌──────────────┐  補間   ┌──────────────────────────────────┐
  │ 19 Newton    │ ─────▶ │ 初期 |R|/|R_ref| = 0.08 (双一次) │
  │ 2〜3 s       │        │ 出発 CFL = 0.25/0.08 = 3         │
  └──────────────┘        │ CFL 3 → 800 まで 2 倍ずつ ≈ 8 段 │
                          │ + 跳ね返り 2〜4 回 = 13 Newton   │
                          │ 16〜17 s                          │
                          └──────────────────────────────────┘
  段を足しても: 粗格子 2.7 s → 1.5 s（-1 s）、細格子 13 Newton のまま
  576×384 では: 粗格子 20 s（288 を Stokes から）→ 13 s（72 からカスケード）、細格子 20〜30 Newton × 8〜10 s
```

細格子側の下限 13 反復は「CFL の梯子」で決まる。乗法形 SER は 1 反復で CFL を高々 2 倍にしか上げないので、
出発 CFL から Newton 収束域（CFL 数百）までの段数 log₂(800/3) ≈ 8 が最低限で、そこに流れ場形成中の跳ね返り
（残差増 → CFL 0.1 倍 → 2 倍ずつ回復）が 2〜4 回乗る。初期場をどれだけ良くしても、この梯子は省略できない
（出発 CFL を上げると §4 の発散域に落ちる）。

読み方:

- **段数**: 1 段（144×96 のみ）と 2 段（72×48 → 144×96）で細格子側は同じ 13 反復。差は粗格子の 2.6 → 1.5 s。

- **補間**: 双一次（初期 0.084、出発 CFL 3）は注入（0.50、CFL 0.5）より細格子側が 4 反復少ないが、
  時間では 2 s 差にとどまる（GMRES 反復数は双一次のほうが高 CFL で多い）。注入のほうが出発 CFL が低い分、
  §4 の発散域に入りにくい。

- **段は全部入れる。** 288×192 を Stokes から解いて 1 段だけ挟むと粗格子 20 s + 細格子 30 反復で Stokes

- **粗格子を 1e-6 まで解くのは損。** 288×192 の段が 41 s（総時間の 20%）。細格子側の反復は 20 で最少だが、

  CFL 30〜100 で跳ね返りが 3〜5 回入る。GMRES 反復数の増え方が前処理の規模依存（運動量 ILU）を示していて、
  次の律速はここ（roadmap TODO）。

### 4.2 機構: 発散は「線形解が実質失敗したステップを採用した」ことで起きる

uturn 144×96 U=2（`cfl_init=0.25`、棄却なし）の発散直前（`diag-uturn2U2-blowup-status41.log`）:

```
it=26 rel=9.7e-03 cfl=10.7 gmres=161
it=27 rel=1.4e-02 cfl=18.3 gmres=163 (gmres not converged: 1.0e-03)
it=28 rel=9.9e-03 cfl=12.3 gmres=200 (gmres not converged: 4.5e-03)
it=29 ... gmres=200   ← 真の残差比 0.3 超のごみ修正量をそのまま採用
it=32 rel=4.4e+09 cfl=34.3 gmres=200   ← 1 ステップで 1e12 倍、以後 CFL を 1e-3 に落としても戻らない
```

因果はこう。

1. uturn は厚さ場 h の変化で Brinkman 抗力が桁で変わり、SIMPLE 型前処理（運動量 ILU + Schur 補元 SA）の
   効きが CFL 10 以上で急に落ちる（GMRES 10〜25 反復 → 160〜200 反復）。
2. 乗法形 SER は「残差が少しでも減れば CFL を上げる」ので、GMRES が限界（restart 40 × 5 回 = 200）に
   張り付いても CFL を上げ続ける。
3. GMRES の 200 反復目の修正量は真の残差比が 0.3〜1 の**ごみ**だが、Newton はそれを足してしまう。
   状態が壊れると、その後 CFL を下げても線形系自体が悪くなっていて回復しない。

つまり **CFL の上限は Newton ではなく線形ソルバーの余力で決まっている**。SER の成長率や上限を触っても
効かなかったのは、崩れる CFL がケースごとに違う（flat 288×192 で 30〜40、uturn U=2 で 12〜18）からで、
「崩れたことを検出して戻す」規則でないと当たらない。

**安全規則（`reject_lin_ratio=0.3`）**: 線形解（前処理を組み直しての再試行後）の真の残差比 |b − Aδ|/|b| が
0.3 を超えたら δ を捨て、CFL を `ser_shrink`（0.1）倍にして同じ場からやり直す。JFNK の差分 matvec は
折れ点（風上切替・max・リミター min）で線形写像から 1e-4〜1e-3 ずれるため FGMRES の「未収束」フラグ
（残差比 1e-3 程度）は常に立っていて信号にならない（status-39 §3.1）。それとは別に、残差比 0.3 超という
「解けなかった」ステップだけを弾く。棄却後は乗法形の梯子で回復するので追加コストは数反復。

```
it=28 rel=9.9e-03 cfl=12.3 gmres=200 (gmres not converged: 4.5e-03)   ← 採用（4.5e-3 は差分ノイズ床）
it=29 linear solve failed (gmres=200, |b-Ax|/|b|=...), rejected, cfl -> 1.81
it=30 rel=4.4e-03 cfl=1.81 gmres=14
...
it=49 rel=5.1e-07 cfl=152   収束（49 反復 17.6 s）
```

### 4.3 機構: なぜ `cfl_init` 0.5 が危ないか

出発 CFL は古典形 `cfl_init·|R_ref|/|R_init|`。Stokes 発進なら 0.5 だが、双一次補間の初期場（|R|/|R_ref| 0.084）
からは **6** で出発し、2 反復で 12 → 20 → 37 に達する。流れ場が形成途中（残差比 1e-2〜1e-1）の CFL 10〜40 は
GMRES の反復数が跳ね上がる域で、そこに一気に入ると §4.2 の失敗が起きる。`cfl_init` 0.25 なら 3 から出発し、
1 反復分だけ余計に梯子を登るかわりに GMRES が健全なうちに流れ場が形成される。0.1 は梯子が 1 段長い分
遅い（flat 288×192 双一次で 13 → 22 反復）。

Stokes 発進（残差比 1 から）でも uturn 144×96 U=1 は `cfl_init` 0.5 で CFL 23.6 の 1 ステップで 9.3e-3 → 7e+1
に跳ねて発散していた（status-40 の既定は uturn で壊れていた。flat 288×192 でしか見ていなかった）。

### 4.4 落とした案と理由

| 案 | 結果 | 理由 |
|---|---|---|
| 古典形目標則（目標 `cfl_init·|R_ref|/|R|` へ 2 倍ずつ） | flat4 双一次 60 反復未収束、uturn 3 件未収束 | 残差が少しでも減れば 2 倍上げるので、乗法形より早く発散域に入る |
| GMRES 反復数で CFL を据え置く（40 / 80 超） | uturn 2 件が 60 反復で未収束 | 据え置いた CFL での収束が遅く（比 1.02〜1.2/反復）、反復上限に届かない |
| 非線形残差が 10 倍超えたら棄却 | uturn2 U=2 は救えない | 壊れた状態を戻せても、線形解が失敗する CFL に再び登って同じ失敗を繰り返す。線形解の失敗そのものを見るほうが早い |
| `ser_shrink` 0.3 / 0.5（減少を穏やかに） | flat4 双一次で発散 | 跳ね返り後も高い CFL に留まり、崩れ続ける |
| `cfl_max` 30 / 100 / 300 | 効果なし〜悪化 | 崩れる CFL がケースごとに違う |

残る非効率は **棄却後の乗法形の這い上がり**（uturn2 U=1 で CFL 1〜5 に 30 反復）で、これは線形ソルバーが
CFL 10 付近で弱いことの裏返し。前処理（Brinkman 抗力の厚さ変化への追従）が次の律速（roadmap TODO）。
