## 1. なぜ 2.5D で足りるのか

### 1.1 スライディングメッシュも移動メッシュも要らない

スクリューは回りバレルは静止しているが、**スクリューと共に回る座標系**に移ると
スクリューが静止し、バレルが逆向きに回る。さらに螺旋チャネルを平面に展開すると、
バレルは**チャネル上面をリード角 φ だけ斜めに滑る平板**になる。

```
        バレル（移動壁）  →→→→→→  V = πDN
   ══════════════════════════════════════
    ↑                                  ↑
    H                            リード角 φ だけ斜めに滑る
    ↓                                  ↓
   ███████████████████████████████████████   スクリュー根元（静止）
        └─ フライト（側壁）
```

**壁が自分自身の面内を接線方向に滑るだけなら、メッシュを動かす必要はない。**
これは Dirichlet 速度境界条件であり、キャビティ流と同じ扱いになる。
座標変換が許されるのは、一定ピッチのスクリュー形状が**螺旋対称性**を持ち、
スクリュー座標系で形状が時間変化しないためである。

スライディングメッシュが必須になるのは以下であり、本設計の Phase 1/2 では現れない。

- **二軸押出** — 2 本のスクリューが噛み合い、隙間形状が時々刻々変わる（螺旋対称性が無い）
- **混練エレメント**（マドック / ダルメージ / ピン）— フライトが途切れて螺旋対称性が壊れる
- 溝付きバレル

### 1.2 自由表面も要らない

押出で自由表面が現れるのは以下だが、いずれも本設計の射程外に置ける。

| 箇所 | 自由表面 | RTD 解析で必要か |
|---|---|---|
| 起動時の充満過程 | あり（過渡） | 不要（RTD は定常運転の量） |
| 飢餓供給 | あり（定常でも部分充満） | 飢餓運転をやる場合のみ |
| 固体輸送・溶融部 | 固体床＋メルトプール（相変化問題） | 不要（計量部を見る） |
| ダイ出口スウェル | あり（粘弾性） | スクリュー外・別問題 |
| **計量部・混練部（充満）** | **無し。単相** | **ここを解く** |

### 1.3 断面 2D で 3 成分が出る

一定ピッチの展開チャネルは断面形状が下流方向に不変なので、完全発達を仮定すると
`∂/∂z = 0`。したがって **2 次元断面を解くだけで 3 成分の速度場が全て出る**。

```
  断面 (x,y) で解く      得られるもの
  ─────────────────────────────────
  u(x,y), v(x,y)    →  断面内の循環流（混合を担う）
  w(x,y)            →  下流方向の輸送（滞留時間を決める）
```

## 2. 支配方程式

座標: `x` = 横断方向、`y` = 深さ（0 = スクリュー根元、H = バレル）、`z` = 下流方向。

樹脂の Reynolds 数は `Re = ρVH/μ ~ 10⁻³` なのでクリープ流れとし、慣性項を落とす。

```
  断面内（x,y）:  ∂u/∂x + ∂v/∂y = 0
                  0 = −∂p/∂x + [∇·(μ(∇u + ∇uᵀ))]_x
                  0 = −∂p/∂y + [∇·(μ(∇u + ∇uᵀ))]_y

  下流方向:       0 = −G + ∂/∂x(μ ∂w/∂x) + ∂/∂y(μ ∂w/∂y)      G = dp/dz（既知の定数）

  粘度:           μ = K γ̇^(n−1)
                  γ̇² = 2[(∂u/∂x)² + (∂v/∂y)²] + (∂u/∂y + ∂v/∂x)² + (∂w/∂x)² + (∂w/∂y)²
```

**構造上の要点**: ニュートン流体（`μ` = 定数）だと断面内問題と下流問題が
**完全に分離する**。`(u,v,p)` は 2D ストークス、`w` は独立したポアソン。
だから厳密解が存在する。非ニュートンにすると `γ̇` が両方の勾配を含むため、
**粘度だけを介して結合**する。反復で解ける。

つまり「ニュートンで厳密解と一致 → 非ニュートンへ」という段階が、
方程式の構造としてそのまま用意されている。

### 2.1 境界条件

| 面 | 条件 |
|---|---|
| `y=0` スクリュー根元、フライト側壁 | no-slip `u=v=w=0` |
| `y=H` バレル（隙間部も含む） | `u = -V sinφ`, `v = 0`, `w = +V cosφ`（`V = πDN`）。符号は §2.1.1 で確定 |
| `x` 両端 | **圧力跳び付き周期**。`P(x+W_t, y) = P(x, y) + Δp`、`Δp = G·L_turn`。`W_t = πD·sinφ`（チャネル 1 ピッチのフライト直交幅）、`L_turn = πD·cosφ`。実装上は `P = βx + p̃`（`p̃` は周期）と分解し、横断方向運動量に一様体積力 `f_x = -β = -G·cotφ` を入れる。§2.1.1 参照 |

`x` 周期の圧力跳びは、**隣のチャネルが同じチャネルの 1 周後**であることに由来する。
これが漏れ流れ（leakage flow）の駆動力になる。

### 2.1.1 幾何の同一視と、そこから出る符号（確定済み）

> **旧版の誤り**: `L_turn = πD/sinφ` としていたが誤り。正しくは `L_turn = πD·cosφ`。
> 旧版の値は 40mm 機で 414mm、正しくは **119.74mm**（旧版は 3.46 倍の過大評価だった）。
> そのまま実装すると漏れ流れの駆動圧を 3.46 倍に見積もる。

バレル面を展開した平面を `(ξ, ζ)` とする（`ξ` = 周方向、1 回転で `πD`。`ζ` = 軸方向）。
フライトは傾き `φ` の平行直線群で `tanφ = リード/(πD)`。下流方向と横断方向は

```
  ẑ = ( cosφ,  sinφ)          x̂ = (-sinφ,  cosφ)
  z = ξcosφ + ζsinφ           x = -ξsinφ + ζcosφ
```

**物理的な同一視はバレルを 1 周すること**、すなわち `(ξ, ζ) ~ (ξ + πD, ζ)`。
これを `(x, z)` で書き直すと

```
  (x, z)  ~  (x - W_t, z + L_turn)      W_t = πD·sinφ ,  L_turn = πD·cosφ
```

つまり `z` は物理領域上で**一価ではなく**、1 周ごとに `L_turn` だけ増える。
圧力の跳びはこの多価性から出る。`p = G·z + P(x,y)` と置けば

```
  P(x + W_t, y) = P(x, y) + G·L_turn
  β ≡ dP/dx = G·L_turn / W_t = G·cotφ        ← D にもリードにも依らない
```

**恒等式** `W_t / L_turn = tanφ`。これらは全てテストで固定してある
（`tests/test_extruder_geometry.py::TestScrewGeometryPhysics`）。

**整合性チェック**: 全圧力勾配ベクトルは `(x, z)` 成分で `(G cotφ, G) ∝ (cosφ, sinφ)`。
これは展開平面の**軸方向 `ζ̂` そのもの**であり、実機で圧力が軸方向にのみ変化する事実と
一致する。大きさは `dp/dζ = G/sinφ`。旧版の `L_turn = πD/sinφ` ではこの整合性が壊れる。

**符号（旧版の「実装時に固定すべき」を確定）**: バレルはスクリュー座標系で周方向 `ξ̂` に
速度 `V = πDN` で滑る。`ξ̂ = -sinφ·x̂ + cosφ·ẑ` なので

```
  u_barrel = -V·sinφ        v_barrel = 0        w_barrel = +V·cosφ
```

`+x` が下流側の隣チャネル、`-x` が上流側。押出（背圧あり）は `G > 0` なので
`f_x = -G·cotφ < 0`、漏れ流れは `-x`（上流へ戻る backflow）。引きずり成分
`u_barrel < 0` も同じ向き。**漏れは押出量を減らす**という古典的描像と一致する。

#### 40mm 機の確定値

```
  φ         = 17.6568°      sinφ = 0.303314   cosφ = 0.952891   tanφ = 0.318310
  W_t       = 38.1156 mm    W = W_t - e = 34.1156 mm    H/W = 0.117248
  L_turn    = 119.7438 mm
  V         = 0.209440 m/s
  u_barrel  = -0.063526 m/s     w_barrel = 0.199573 m/s
```

### 2.1.2 押出量は `∫∫w dA` ではない（実装で判明）

隙間があると `Q = ∫∫w dA` は**閉チャネルより増える**。隙間 `e×δ` は `w` が最大に
なるバレル直下に流路を足すからで、40mm 機・`G=5×10⁶` の実測で +0.3%。
だがこれは押出量ではない。

軸方向の一定面 `ζ = const` を通る流束を取る。この面は展開平面上で `ξ̂` 方向に
円周 `πD` 分伸びており、`ξ̂` に沿って進むと `x` が 1 周期 `W_t` 変化する。

```
  Q_axial = ∫∫ (u cosφ + w sinφ) dl dy
          = (1/sinφ)[ cosφ ∫∫u dA + sinφ ∫∫w dA ]
          = cotφ · ∫∫u dA + ∫∫w dA
```

断面内は 2 次元非圧縮なので**どの `x` 面を通る流束も同じ**（= `Q_leak`）であり、
`∫∫u dA = Q_leak · W_t`。恒等式 `cotφ · W_t = L_turn`（§2.1.1）を使うと

```
  Q_axial = Q + L_turn · Q_leak
```

「漏れ 1 単位が材料を `L_turn` だけ下流方向に戻す」という描像そのもの。
`Q_leak < 0`（後戻り）なので押出量は減る。40mm 機の実測:

| 量 | 閉チャネル | 隙間 0.1mm | 比 |
|---|---|---|---|
| `Q = ∫∫w dA` | 1.1911e-5 m³/s | 1.1945e-5 m³/s | **+0.3%** |
| `Q_leak` | 0 | −3.239e-6 m²/s | — |
| `L_turn·Q_leak` | 0 | −3.879e-7 m³/s | — |
| **`Q_axial`** | 1.1911e-5 m³/s | 1.1558e-5 m³/s | **−3.0%** |

**古典的な「隙間は押出量を減らす」は `Q` ではなく `Q_axial` の話。**
ゲート G3 で OpenFOAM と比べるのも、RTD の平均滞留時間 `⟨t⟩ = z_end·A_free/Q` を
規格化するのも `Q_axial` を使う（粒子は `x` 周期の跳びで `z` が ±`L_turn` 動くので、
その寄与を含んだ実効流量が `Q_axial` になる）。

### 2.2 フライト隙間

混練性への寄与が最大の部位は**フライト頂部の隙間を越える漏れ流れ**である。
チャネル間で物質を入れ替えるのはほぼこれ。

隙間 `δ` は 0.1 mm 級、チャネル深さ `H` は 5 mm 級で **50:1 の寸法比**になる。
別プロジェクト `1a/a02` のボクセルメッシュ品質ベンチマークの結論
（誤差は**最狭方向のセル数だけで決まる**。1% なら 20 セル、0.1% なら 63 セル）から、
**隙間方向に 16〜20 セルを確保する不等間隔格子**を用いる。
`StructuredMeshProcess` が不等間隔直交格子を既に持つので、この経路は自前の道具で足りる。

断面 2D なので、隙間に 6 μm セルを入れても総セル数は現実的に収まる。

## 3. 検証の階段

**G1/G2 を通らなければ先へ進まない。**

| ゲート | 内容 | 真値 |
|---|---|---|
| **G1** | ニュートン・隙間無し・純引きずり流れ（`G=0`） | `Q = V H W Fd / 2`。`Fd(H/W)` は級数解 |
| **G2** | ニュートン・隙間無し・引きずり＋圧力 | `Q = (VHW/2)Fd − (WH³/12μ)G·Fp` の直線全体 |
| **G3** | 隙間あり（解析解が無い領域） | **ykep-cae と OpenFOAM の一致**（1% 以内） |
| **G4** | 粒子追跡・RTD | 単純せん断で厳密軌跡（G4a）。`⟨t⟩ = V/Q` の厳密関係（G4b） |
| **G5** ✅ | 文献 RTD との照合（Phase 2 の前提） | Pinto & Tadmor 1970 の解析 RTD。浅溝極限 `H/W → 0`・閉チャネル・長区間で分位点 3%/3%/5%・曲線 5% 以内に収束（[設計](extruder-g5-literature-rtd.md)、[レポート](../reports/extruder/g5-literature-rtd.md)） |

> `Fd` / `Fp` は `H/W` の関数（Tadmor & Gogos の形状係数）。
> **文献値をハードコードせず級数解を自前で実装し、文献値と一致することを pytest で固定する。**
> `1a/a02` で矩形管の `f·Re` 級数解に対して行ったのと同じ方針。

> **級数の桁落ち対策（確定）**: 古典形 `F_d = (16/(π³h))Σ_{i odd} tanh(ai)/i³`
> （`a = πh/2`, `h = H/W`）は `tanh → 1` の尾が `1/i³` でしか減衰せず、
> 倍精度に届かせるのに `i ~ 10⁵` 項を要する。`tanh(x) = 1 − 2/(e^{2x}+1)` と分解し、
> 定数部を ζ の閉形式に置き換えると残る級数が**指数減衰**する。
>
> ```
>   Σ_{i odd} 1/i³ = (7/8)ζ(3)        Σ_{i odd} 1/i⁵ = (31/32)ζ(5)
>
>   F_d = (16/(π³h)) [ (7/8)ζ(3)   − Σ_{i odd} t(ai)/i³ ]     t(x) = 2/(e^{2x}+1)
>   F_p = (192/(π⁵h)) [ (31/32)ζ(5) − Σ_{i odd} t(ai)/i⁵ ]
> ```
>
> `1 − tanh(x)` を引き算で作らず `2/(e^{2x}+1)` で直接評価するのが核心。
> 打ち切りは `a·i > 25`。浅溝側（`h → 0`）で括弧内が `π³h/16` に縮む相対的な
> 桁落ちは残るが、損失は `h` の対数でしか増えず `h = 10⁻³` でも 13 桁が残る（実測確認済み）。
> `h < 10⁻⁶` は漸近式に切り替える。

> **級数の非自明な性質**: `H/W = 1`（正方形断面）で `F_d = 1/2` になる。
> 参照値: `F_d(0.117248) = 0.93636312`, `F_p(0.117248) = 0.98726875`（40mm 機の `H/W`）。

### 3.1 RTD 検証で分かったこと（実装時に判明）

**平均滞留時間には厳密関係がある。** (x, y, ζ) 空間で流れは体積保存
（`∂u/∂x + ∂v/∂y + ∂(dζ/dt)/∂ζ = 0`）なので、`ζ=0` から `ζ=z_axial` の領域について

```
  ⟨t⟩ = 体積 / 流束 = z_axial · A_free / (sinφ · Q_axial)
```

補間誤差・脱出時刻の内挿ミス・種まき重みの誤りを同時に捕まえる強い検査で、
文献の RTD 曲線との目視比較よりはるかに鋭い。ゲート G4b はこれで判定する。

**ただし判定は「隙間あり」で行うこと。** 隙間ゼロの閉チャネルでは
`⟨t⟩` が格子細分で収束しない（実測 1.10 → 1.29 → 3.40 → 1.38 と不規則）。

| 構成 | `⟨t⟩ / 理論値`（格子を細かくしていく） |
|---|---|
| 隙間あり δ=0.1mm | 0.986 → 0.988 → 0.990 → 0.995（収束） |
| 隙間ゼロ（閉） | 1.100 → 1.286 → 3.396 → 1.380（発散気味） |

**当初「理由は物理」としたが、大半は数値効果だった（G5 で判明）。** 閉チャネルでは
壁沿いの閉じた流線が周方向へ逃げ場を持たず、隅の周期が発散するデッドゾーンは
確かにある。だが上の表の発散気味の平均は、既定の時間刻み `cfl = 1.0` で RK4 が
ψ 双一次補間のセル境界（速度勾配が不連続）を 1 ステップで跨ぎ、周回を重ねる
うちに粒子が流線を横切って壁際へ流れ込む**流線ドリフト**が主因。`cfl = 0.1` にすると
閉チャネル H = 4/2/1 mm で `⟨t⟩/理論値 = 1.003 / 0.997 / 0.998` と収束し、止まる粒子も
消える（`ParticleTrackInput.cfl` の docstring、`TestStreamlineDrift`、
[G5 レポート §3.4](../reports/extruder/g5-literature-rtd.md)）。周回 1〜2 回の
短い区間（G4b の z = 0.2 m）ではドリフトが見えないので G4b の判定は変わらない。
隙間がドリフトした材料の逃げ道になって平均を安定させる、という観察自体は正しい。

> **示唆**: 隙間が壁際の材料の逃げ道になるのは実機でも同じだが、閉チャネルの
> 平均が「当てにならない」のは物理ではなく追跡の時間刻みの問題。長い区間を追う
> ときは `cfl ≤ 0.25`。

**平均が裾支配なら、実務ではパーセンタイルを見る。** `t_p10` / `t_p50` /
広がり `t_p90/t_p10` と累積せん断の中央値 `γ_p50` はどちらの構成でも格子に対して
安定（実測 `t_p50/⟨t⟩_theory ≈ 0.81`、`spread ≈ 2.1`、`γ_p50 ≈ 89〜98`）。
工程設計で使うのはこちら。

**境界層の扱い。** バレル面の軸方向速度は
`u_barrel cosφ + w_barrel sinφ = −V sinφcosφ + V cosφsinφ = 0` と厳密にゼロ
（バレルは周方向にしか動かない）。その直下と根元直上の材料は滞留時間が発散する。
重みは壁からの距離で消えるので積分は収束するが、有限ステップでは閉じないので、
定常な周回軌道では `ζ ∝ t` を使って `t_res = t·z_axial/ζ` で外挿する。
**外挿には歯止めが要る**: `ζ` がほとんど進んでいない粒子は前提を満たさず、
係数が発散して `⟨t⟩` を 10 桁単位で壊す（実測）。`ζ ≥ 0.1·z_axial` を条件にし、
残りは未解決として報告する。あわせて 1 ステップの時間刻みにも上限
（理論平均滞留時間の 2%）が要る。淀み点では `dt = cfl·dx/|u|` が発散するため。

### 4.0 既存 SIMPLE ソルバーを使わない（実装計画で確定）

**事実（実測）**: `NaturalConvectionInput` は `dx = Lx/nx` のプロパティを持ち、
`natural_convection/assembly.py:300` は `dx, dy, dz = inp.dx, inp.dy, inp.dz` で
**スカラー**として受ける。つまり既存の Navier-Stokes ソルバーは**等間隔格子専用**。
`StructuredMeshProcess` が不等間隔格子を作れるのは事実だが、NS ソルバーはそれを食えない。

| 押出が要求するもの | 既存 SIMPLE | 判定 |
|---|---|---|
| 隙間 0.1mm に 16〜20 セル（深さ 4mm と 40:1） | 等間隔のみ | ✗ |
| 場としての粘度 `μ(x,y)` | スカラー定数 | ✗ |

## 5. OpenFOAM 側の検算構成

別プロジェクト `~/work/1a/a02` で構築した資産をそのまま使う。

- `~/work/1a/a02/tools/of` — Docker ラッパ（資源上限つき、`OF_IMG` でイメージ切替）
- イメージ: `opencfd/openfoam-run:2312`（通常）/ `opencfd/openfoam-dev:2312`（`codedSource` 用。
  **run イメージにはコンパイラが無い**）

構成:

- `z` 方向 1〜数セルの 3D メッシュ + `cyclic`、体積力（`vectorSemiImplicitSource`）で `G` を与える
  — `1a/a02` の周期完全発達ケースと同一の手口
- 非ニュートンは `transportModel` の `powerLaw` / `BirdCarreau` が**標準装備**
- `x` は素の `cyclic` でよい。**`fixedJump` は不要**。圧力跳びは `P = βx + p̃` の分解で
  横断方向の一様体積力に還元済みなので、体積力ベクトルを `(-β, 0, -G) = (-G·cotφ, 0, -G)`
  [N/m³] とすれば `x`・`z` 両方の駆動力が 1 つの `fvOptions` に収まる（§2.1.1）
- **カスタムソルバ不要**で `simpleFoam` のまま行けるはず

> `1a/a02` の教訓: 完全発達で対流項が消える問題に `simpleFoam` を使うと、
> 存在しない圧力-速度連成を反復して極端に遅くなる。本件は断面内に実際の
> 循環流があるので `simpleFoam` で妥当だが、**収束が異様に遅い場合は
> 連成の要否を疑うこと。**

**実装で確定した構成**（`experiments/extruder/of_case.py`、結果は [G3 レポート](../reports/extruder/g3-openfoam.md)）:

- 格子は **ykep と同一**にする。`ScrewGeometryProcess` の dx/dy は等比区間の並びなので
  blockMesh の多区間 grading `((fraction n ratio) ...)` で厳密に再現でき、フライトは
  `topoSet`（boxToCell + invert）→ `subsetMesh -patch screw` で抜く。compare 時にセル中心の
  ずれ < 1e-3 セル幅を検査する
- **緩和係数は U 0.999 / p 1.0（SIMPLEC）**。緩和係数 α は擬似時間刻み α/(1−α)·V/a_P を
  与え、隙間セル（Δy = 5 μm）では a_P ≈ 2ν/Δy² が巨大なので α=0.9 では最も滑らかな
  誤差モードが 1 反復あたり 1−7e-5 しか減衰しない（1D で 5000 反復後も残差 1e-3）。
  α=1 は SIMPLEC の `1/(1/rAU − H1)` が純拡散で 0 割になり sigFpe。上の教訓の定量版
- べき乗則は **ニュートン収束解から起動する**。U=0 から始めると γ̇=0 → ν=nuMax で
  a_P がさらに 150 倍になり、粘度が下がるには速度が育つ必要がある鶏と卵で反復が 1 桁増える
- `powerLaw` の (k, n) は ρ=1 で ykep の (K, n) にそのまま対応（1D Poiseuille 厳密解で 0.5% 以内を確認）。
  `nuMax = K·γ̇_min^(n−1)` で ykep のクランプと揃える
- OpenFOAM は writeInterval の倍数でしか書かない（endTime では書かない）。段階実行するなら
  writeInterval = 段の長さ。`residualControl` の U は成分の max なので 1D（Uy≡0）では発火しない

## 8. 未決事項 → 全て確定済み

旧版の未決事項 6 件は実装計画の策定時に全て確定した。

| 旧・未決事項 | 確定内容 | 参照 |
|---|---|---|
| `V sinφ` の向きと `Δp` の符号 | `u_barrel = -V sinφ`, `w_barrel = +V cosφ`, `Δp = +G·L_turn`（`+x` が下流） | §2.1.1 |
| `Fd`/`Fp` の級数と桁落ち対策 | `tanh(x)=1−2/(e^{2x}+1)` 分解 + ζ 閉形式。指数減衰する級数に変形 | §3 |
| 非ニュートンの反復スキーム | Picard（逐次代入）+ 粘度の緩和 `ω = 0.5`。Newton は不採用 | 計画 Task 6 |
| 粒子追跡の時間刻み | 粒子ごとに `dt = CFL·min(dx/\|u\|, dy/\|v\|)` を毎ステップ再計算（CFL=1.0、RK4）。淀み点で dt が発散するので上限 = 理論平均滞留時間の 2% | `tracker.py` |
| RTD の粒子数と初期配置 | **決定論的**: 流体セル 1 個に 1 粒子（40 mm 機で 16,960 個）、重み = 軸方向流束 `max(u cotφ + w, 0)·dA` を追跡と同じ双一次場から取る。1 点求積がセル積分に厳密なのでモンテカルロ誤差ゼロ | `tracker.py` |
| 諸元 | 仮の 40mm 機。実機は `ScrewSpec` を差し替えるだけ（検証枠組みは `H/W` にのみ依存） | §6 |

**Newton を採らない理由**: 見かけ粘度項のヤコビアンは `∂μ/∂γ̇ · ∂γ̇/∂(∇u)` を通じて
全成分に密に絡み、組み立てコストが線形解 1 回分を大きく超える。一方 Picard は
**線形解が毎回厳密**なので、反復が粘度場の不動点探索だけに集約される。

**粒子追跡で速度を直接補間しない理由**: 離散的な発散ゼロが壊れ、粒子が渦中心に落ちたり
壁に貼り付いたりして RTD の裾が偽物になる。節点流れ関数 `ψ` を双線形補間して
`u = ∂ψ/∂y`, `v = -∂ψ/∂x` を作れば、セル内で厳密に発散ゼロになる。
